base-helm-chart

v0.18.0

Basic helm chart for deploying services

Helm Repository

Add the repository to your Helm installation: 

helm repo add base-helm-chart https://tylerpitcher.github.io/base-helm-chart/
        helm repo update

Usage

Add the chart as a dependency: 

dependencies:
        - name: base-helm-chart
            version: 0.18.0
            repository: "https://tylerpitcher.github.io/base-helm-chart/"
